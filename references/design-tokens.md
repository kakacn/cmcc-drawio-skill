# CMCC 流程图设计令牌与布局规则

## 颜色令牌

| 令牌 | 值 | 用途 |
|---|---|---|
| `--cm` | #008FD7 | 移动蓝主色：箭头、菱形边框、编号块渐变、卡片顶条 |
| `--cm-deep` | #0067AC | 渐变深色端 |
| `--cm-dark` | #0A3D66 | 标题/卡片标题深蓝 |
| `--cm-ink` | #33566E | 卡片正文灰蓝 |
| `--cm-mute` | #6B8CA3 | 页脚弱化文字 |
| `--cm-line` | #C9E2F2 | 卡片描边、分隔线 |
| `--warn` | #F39800 | 退回修订虚线与标签（唯一非蓝色强调） |
| 页面背景 | #F0F8FE → #FFFFFF | 顶部浅蓝渐变到白 |

横幅渐变：`linear-gradient(100deg,#0AA5E2 0%,#0078BE 55%,#005E9C 100%)`，底部叠两条白色半透明波形（opacity .18/.28）。

## 字体

- 全局：`-apple-system,"PingFang SC","Microsoft YaHei",sans-serif`
- 标题：31px / 800 / 字距 .1em；副标题 13.5px 白色 85%
- 卡片标题 16.5px / 800；编号块 19px / 800 白字渐变底（#12A6E4→#0067AC，圆角 10px）
- 卡片正文 11.8px / 行高 1.7 / #33566E，≤45 字

## 布局参数（2000px 画布）

- 横幅高 128；卡片行 top 196，卡片高 196，左右边距 40，卡间距 45（≤8 卡时每卡 ≥200px 宽）
- 菱形 150×150，top 448，顶点距中心 63px；对齐于所属卡片正下方
- 退回总线：首条 y=700，间距 96；多条时汇入横线左右各错开 ±16px 以上
- 画布高 = 700 + (决策数-1)×96 + 150；无决策节点时 620
- 连线：主流程 #008FD7 实线 3px；退回 #F39800 虚线 `9 7`；箭头 marker 7px
- 页脚：左右分置，11.5px #6B8CA3，底边距 26

## 流程语义约定

- 蓝色实线 = 主流程（从左到右）；橙色虚线 = 退回修订；白底蓝边菱形 = 审议/判断
- 菱形"是"：右顶点出肘线（水平→向上）进入下一步卡片底部，标签"是"
- 菱形"否"：底顶点出虚线总线（向下→横向→向上）退回目标卡片底部，标签如"否 · 退回修订草案"
- 终点卡片：深蓝渐变实心 + 白字 + 橙色 END 角标
- 页眉右侧图例三项：主流程 / 退回修订 / 审议判断；页脚注明依据文件与手册归属

## A4 手册版宽度规则（cmcc-flow-template-a4.html）

图片宽度以 A4 纸（210mm）为上限、左右各预留 25mm 页边距 → **版面设计宽度 160mm**，插入 Word 时图片宽度设 16cm，1:1 还原设计字号。

| 项 | 规则 |
|---|---|
| 画布 | 1600px 对应 160mm（10px/mm），页面高 1390px |
| 导出 | `--window-size=1600,1390 --force-device-scale-factor=1.2` → 1920px 宽 ≈ 305dpi@160mm |
| 布局 | 6 卡 3+3 两行（row1 top 200，row2 top 930，卡 350×360px），两行均居中；判断菱形 200×200 挂第一行第 3 卡下方（top 630） |
| 走向 | 第一行 01→02→03；菱形"是"从左顶点沿 y=730 横移通道下行进入第二行第 1 卡顶部；"否"沿 y=870 橙色虚线总线退回第一行第 2 卡底部；第二行 04→05→06 从左到右 |
| 交叉 | "否"上行竖线与"是"横移通道交叉属预期，蓝实线/橙虚线可区分，不做跳线 |
| 字号 | 图题 40px(≈11pt)、副题 25px、卡片标题 34px(≈9.5pt)、正文 26px(≈7pt)、图例 24px |
| 页边距 | 内容区 x 40–1560（左右各 4mm），页脚仅左侧依据行 |
| 适用 | 固定 6 步 + 1 判断（退回到第 2 步）的流程；其他步数/退回关系需手工调布局 |
| 手册规范 | 标题：`中国移动基层工会{流程名称}流程图`；页脚：`依据：中国移动基层工会工作标准化手册（工会经费管理模块）`，无右侧页脚 |

### 8 步 + 双判断变体（预算编制与审批图实测版式）

步骤多或判断节点超过 1 个时，用 **4 卡行 + 6 格行** 结构（示例见预算编制与审批流程图）：

- 第一行 4 张 350×360 大卡（01–04），第二行 6 格：4 张 230×300 小卡 + 2 个 160px 菱形行内排列（05 ◇ 06 07 ◇ 08），菱形即流程节点，向右即"是"，无需肘线
- 小卡标题换行布局：编号块独立一行，标题另起一行（28px），desc ≤28 字
- 行间转折：末卡底部偏左下行 → 通道 y=900 → 首卡顶部入线
- 退回通道：各判断节点顶顶点上行 → 独立通道（y=640 / y=700）→ 汇入退回卡底部左右错开 ±20px
- 蓝实线转折竖道与橙虚线退回通道交叉属预期，避免蓝蓝交叉即可
- 画布同为 1600×1390（160×139mm），导出 scale 1.2

## drawio XML 样式映射

需要 drawio 可编辑源文件时按下表设置 style 字符串：

| 元素 | drawio style |
|---|---|
| 步骤卡片 | `rounded=1;arcSize=8;fillColor=#ffffff;strokeColor=#C9E2F2;verticalAlign=top;spacingTop=14;fontSize=16;fontStyle=1;fontColor=#0A3D66;` 顶部蓝条用独立小矩形叠加 |
| 编号块 | `rounded=1;arcSize=20;fillColor=#008FD7;strokeColor=none;fontColor=#ffffff;fontSize=16;fontStyle=1;` |
| 判断菱形 | `rhombus;fillColor=#ffffff;strokeColor=#008FD7;strokeWidth=2;fontColor=#0A3D66;fontSize=13;fontStyle=1;` |
| 主流程箭头 | `strokeColor=#008FD7;strokeWidth=2;endArrow=block;endFill=1;` |
| 退回箭头 | `strokeColor=#F39800;strokeWidth=2;dashed=1;dashPattern=9 7;endArrow=block;endFill=1;` |
| 终点卡片 | `rounded=1;fillColor=#005E9C;strokeColor=none;fontColor=#ffffff;` |
| 页面背景 | drawio 页面背景色 #F0F8FE，或导出后由 HTML 版本负责底色 |

生成 XML 后用 `mcp__drawio__open_drawio_xml` 打开核对，节点坐标按上表布局参数换算。
